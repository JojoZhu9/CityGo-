# Contributing to CityGo

CityGo is a Mobile Computing (COMP3011J) Group 04 course project. Contributions are welcome for review, but they require maintainer acceptance before inclusion.

## Before You Contribute

- Search existing issues and pull requests before opening a new one.
- Keep changes focused and explain the user-facing effect.
- Do not commit API keys, runtime databases, APKs, local paths, or other generated artifacts.
- Test Android changes with the relevant Gradle task when your local SDK is available.
- Use the issue and pull-request templates, including screenshots for UI changes.

## Contribution Review

Maintainers review contributions for course-project scope, correctness, security, and documentation. Submission of a contribution does not guarantee acceptance.
